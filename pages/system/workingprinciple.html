02 — SYSTEM

Working Principle

Understanding the physics and logic behind the detection and actuation loop.

1. Ultrasonic Detection

The HC-SR04 sensor operates by transmitting high-frequency sound waves (40 kHz) and calculating the time it takes for the echo to return. The Arduino continuously pulses the trigger pin for 10 microseconds.

If an object (e.g., a hand or a glass) disrupts the wave within the predefined threshold distance (e.g., < 15cm), the system interprets this as an active dispense request.

2. Servo Actuation

Upon positive detection, the microcontroller sends a PWM (Pulse Width Modulation) signal to the SG90 servo motor. The motor rotates from its resting state (0°) to an open state (e.g., 90°), physically pulling the dispenser valve open.

To prevent overflow, the system includes a time-delay buffer. Once the object is removed, the servo returns to 0°, securely closing the valve.
