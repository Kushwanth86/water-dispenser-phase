PIN ASSIGNMENTS

Arduino Uno Connection Map

The following pin assignments match the current Arduino program used in the Phase 1 prototype.

D6

Servo Motor 1 Signal

Digital pin 6 provides the control signal for the first SG90 servo motor.

D7

Servo Motor 2 Signal

Digital pin 7 provides the control signal for the second SG90 servo motor.

D9

HC-SR04 Trigger

Digital pin 9 sends the trigger pulse used to initiate an ultrasonic distance measurement.

D10

HC-SR04 Echo

Digital pin 10 receives the echo pulse duration generated by the ultrasonic sensor.

A4

LCD SDA

On the Arduino Uno, A4 is used as the I2C Serial Data line for communication with the LCD module.

A5

LCD SCL

On the Arduino Uno, A5 is used as the I2C Serial Clock line for communication with the LCD module.

Programmed Control Values

These parameters directly control the behavior of the Phase 1 prototype.

15

90

openAngle

Value: 90°

Defines the servo position used to operate the tap into its open state.

0

closeAngle

Value: 0°

Defines the servo position used when the tap mechanism is closed.

Value: 3000 ms

Determines how long the servo mechanism remains in the open position during one dispensing cycle.

SENSOR CONFIGURATION

Ultrasonic Measurement Parameters

10µs

Trigger Pulse

The Arduino sends a HIGH pulse of approximately 10 microseconds to the HC-SR04 trigger pin.

ECHO

Echo Measurement

The program measures the HIGH pulse duration on the echo pin using pulseIn().

0.034

Distance Conversion

The program uses approximately 0.034 cm/µs for the speed of sound in the distance calculation.

÷2

Round-Trip Correction

The calculated travel distance is divided by two because the sound travels to the object and back to the sensor.

POWER CONSIDERATION

Servo Power Requires Special Attention

SG90 servo motors can draw significantly more current than the ultrasonic sensor or LCD, especially during startup, movement or mechanical load.

For a reliable physical prototype, the servo power source should be capable of supplying adequate current. If an external regulated supply is used for the servos, its ground should share a common reference with the Arduino ground so that servo control signals operate correctly.

The exact power arrangement should match the actual prototype wiring and power source used during testing.
