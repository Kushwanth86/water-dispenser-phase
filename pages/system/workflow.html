System Workflow

Operational sequence from object detection to completion of the dispensing cycle.

1. Initialization

System powers on, LCD displays ready message, and servo locks valve at 0°.

2. Scanning Phase

Ultrasonic sensor actively pings distance while LCD reads "Place Glass".

3. Threshold Trigger

If distance is < 15cm, decision logic validates container presence.

4. Actuation

Servo rotates to 90°, LCD shows "Dispensing...", and water flows.
