SYSTEM WORKFLOW

One Continuous Automated Control Loop.

AquaSense continuously measures distance, evaluates the detection condition and controls the dispensing mechanism automatically. Every cycle follows a defined sequence from sensing to actuation, feedback and reset.

CONTROL FLOW

Complete AquaSense Workflow

Follow the control path from system startup through hand detection, dispensing and return to continuous monitoring.

01
START

System Power-On

Electrical power is supplied to the Arduino Uno and connected system components.

02
INITIALIZATION

Controller Initializes Hardware

Arduino initializes serial communication, LCD operation, ultrasonic sensor pins and both SG90 servo motors.

Servo 1 → 0°
Servo 2 → 0°

03
STARTUP FEEDBACK

LCD Displays Startup Message

The user sees:

Automatic Water
Dispenser

The message remains for approximately two seconds.

04
SENSING

HC-SR04 Measures Distance

Arduino sends a trigger pulse to the HC-SR04 ultrasonic sensor.

The ultrasonic wave reflects from an object and returns to the sensor as an echo.

05
PROCESSING

Distance Is Calculated

Arduino converts the echo travel time into distance.

Distance = Duration × 0.034 ÷ 2

06
READY STATE

System Waits for User

The LCD displays:

Place Hand
Dist: XX.X cm

Distance monitoring continues repeatedly.

07
DECISION

Is a Hand Within 15 cm?

Arduino evaluates:

Distance > 0 cm
AND
Distance ≤ 15 cm

NO → Continue Monitoring YES → Start Dispensing
08
ACTUATION

Servo Motors Open the Tap

Both servo motors receive the open position command.

Servo 1: 0° → 90°
Servo 2: 0° → 90°

Servo movement mechanically operates the tap.

09
DISPENSING

Water Is Dispensed

The LCD displays:

Dispensing
Water...

The tap remains open for approximately three seconds.

10
AUTOMATIC CLOSE

Servo Motors Close the Tap

After the dispensing interval, both servos return to their closed position.

Servo 1: 90° → 0°
Servo 2: 90° → 0°

11
USER FEEDBACK

Completion Message Appears

The LCD displays:

Thank You
Visit Again

The message remains visible for approximately two seconds.

12
LOOP

System Returns to Monitoring

The LCD is cleared and the Arduino returns to the beginning of its main loop.

A new distance measurement is taken and the system waits for the next valid detection.

DECISION LOGIC

The Critical Decision Point

The dispensing mechanism does not activate for every sensor reading. Arduino first validates the measured distance.

NO

No Valid Detection

If the measured distance is greater than 15 cm, the servos remain closed.

The system continues measuring distance approximately every 200 milliseconds.

YES

Valid Detection

If the distance is greater than zero and less than or equal to 15 cm, Arduino recognizes a valid detection.

The dispensing sequence starts immediately.

RUN

Controlled Cycle

Once triggered, the program completes the full dispensing sequence before returning to normal distance monitoring.

TIMING SEQUENCE

Timing Inside One Dispensing Cycle

Several programmed delays determine how long messages and mechanical actions remain active.

2 sec STARTUP DISPLAY
3 sec WATER DISPENSING
2 sec THANK-YOU DISPLAY
200 ms NORMAL LOOP DELAY
COMPLETE FLOW

AquaSense Control Sequence

START → Initialize Arduino → Initialize LCD → Attach Servos → Set Servos to 0° → Display Startup Message → Trigger HC-SR04 → Measure Echo → Calculate Distance → Display Distance → Check ≤ 15 cm → Open Servos to 90° → Dispense for 3 Seconds → Close Servos to 0° → Display Thank You → Return to Sensor Monitoring.

FUNCTIONAL RESPONSIBILITIES

Hardware Roles During the Workflow

US

HC-SR04

Continuously provides the distance information required for touchless hand detection.

MCU

Arduino Uno

Controls the entire workflow including sensing, calculation, decisions, timing, servo commands and LCD updates.

SRV

Dual SG90 Servos

Perform the physical actuation required to open and close the water tap mechanism.

LCD

16×2 I2C LCD

Provides visual feedback for startup, monitoring, dispensing and completion states.
