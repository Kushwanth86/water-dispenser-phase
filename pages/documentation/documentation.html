PROJECT REPORT

What the Engineering Report Represents

The project report acts as the technical record of Phase 1. It explains not only what was built, but also how the individual engineering domains work together to create the complete prototype.

01

Project Concept

Defines the problem, proposed solution, objectives and overall purpose of the touchless dispensing system.

02

System Architecture

Describes how sensing, embedded processing, user feedback and mechanical actuation are connected.

03

Hardware Design

Documents the Arduino Uno, HC-SR04, servo motors, LCD and supporting electrical components.

04

Circuit Integration

Records the electrical connections, control pins and relationships between the hardware components.

05

Embedded Software

Explains the Arduino control logic, sensing process, decision conditions and servo actuation sequence.

06

Mechanical Design

Documents the custom CAD enclosures and mechanical structures developed for the prototype.

USER MANUAL

From Prototype to Practical Operation

The user manual focuses on using the product rather than designing it. It provides the information required to understand the prototype, prepare it for use, operate it correctly and respond to common issues.

01
INTRODUCTION

Understand the Product

Learn what AquaSense is, what the Phase 1 prototype does and how the touchless dispensing concept operates.

02
SETUP

Prepare the System

Review the required connections, mechanical positioning and preparation steps before operating the prototype.

03
OPERATION

Use the Touchless Dispenser

Follow the correct sequence for powering the system, positioning a hand and completing a dispensing cycle.

04
SAFETY

Operate Responsibly

Follow electrical, mechanical and water-handling precautions while using the prototype.

05
SUPPORT

Troubleshoot Common Issues

Use troubleshooting guidance to identify basic sensor, servo, LCD or power-related problems.
