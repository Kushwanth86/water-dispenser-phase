FILE GUIDE

How to Use Each File Type

Different engineering files require different software depending on whether you want to read, program or manufacture the design.

PDF

PDF Documents

Open using a web browser or any standard PDF reader. These files contain the project report and user manual.

INO

Arduino Sketch

Open the .ino file using Arduino IDE to inspect, edit, compile and upload the embedded program to an Arduino Uno.

STL

3D Models

STL files can be opened in CAD viewers or imported into slicing software before 3D printing.

IMPORTANT

Before Using the Engineering Files

01

Verify Hardware

Confirm that the physical circuit matches the pin assignments used in the Arduino source program before uploading modified code.

02

Check CAD Dimensions

Verify enclosure dimensions and component fit before committing to a final 3D print.

03

Keep Original Files

Maintain an unchanged copy of the original Phase 1 files before making software or mechanical modifications.
