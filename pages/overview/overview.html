Project Overview

Phase 1 Prototype of the Automatic Water Dispensing System.

The Problem

Traditional water dispensers require physical contact, creating cross-contamination risks in public, office, or laboratory environments. Furthermore, manual valves often lead to mechanical wear and water wastage if left slightly open.

The AquaSense Solution

AquaSense is an automated mechatronic solution designed to eliminate the need for physical interaction. By leveraging an ultrasonic detection matrix, an embedded Arduino microcontroller interprets user presence and mechanically triggers a servo-actuated valve mechanism.

Primary Objectives

  • Contactless Operation: 100% hands-free liquid dispensing.
  • Precision Timing: Regulate water flow using algorithmic servo control.
  • User Feedback: Real-time status display via an integrated 16x2 LCD interface.
  • Modular Design: Component architecture designed for easy swapping, testing, and eventual Phase 2 scaling.
