06 — TESTING

Methodology & Results

Empirical evaluation of the prototype's sensor accuracy and mechanical reliability.

Primary Test Matrix

The following conditions were tested over 50 consecutive cycles to determine the operational reliability of the dispensing loop.

Test Condition Expected Behavior Actual Behavior Result
Object < 15cm (Center) Valve opens instantly Valve opens at 180ms latency PASS
Object < 15cm (Edge) Valve opens Intermittent detection MARGINAL
Object Removed Valve closes (1s delay) Valve closes accurately PASS
Continuous Object (10s+) Valve remains open Valve remains open PASS

Observations & Limitations

  • Acoustic Interference: Glass containers occasionally reflect ultrasonic waves at severe angles, causing micro-stutters in detection.
  • Mechanical Wear: The SG90 servo gear exhibits slight heat generation after 20 continuous actuations. A metal-gear variant is recommended for Phase 2.
