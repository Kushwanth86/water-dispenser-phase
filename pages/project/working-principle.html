WORKING PRINCIPLE

How the Touchless Dispensing System Works

The Phase 1 prototype follows a programmed sensing-and-actuation sequence. The ultrasonic sensor measures distance, the Arduino evaluates the reading, and the servo mechanism controls the tap when the detection condition is satisfied.

OPERATION SEQUENCE

Step-by-Step System Operation

The following sequence represents the behavior implemented in the Phase 1 Arduino program.

01
INITIALIZATION

System Powers On

When the system starts, the Arduino Uno initializes serial communication, the LCD, ultrasonic sensor pins and both servo motors.

Servo 1 → 0° Servo 2 → 0° LCD → Active
02
USER FEEDBACK

Startup Message Appears

The 16×2 LCD displays the startup message “Automatic Water / Dispenser” for approximately two seconds before entering normal operation.

Automatic Water Dispenser
03
SENSING

Ultrasonic Distance Is Measured

Arduino sends a short trigger pulse to the HC-SR04. The sensor emits an ultrasonic pulse and measures the time required for the echo to return.

Distance = (Echo Time × Speed of Sound) ÷ 2

Division by two accounts for the sound travelling from the sensor to the object and then returning to the sensor.

04
READY STATE

System Waits for a Hand

During normal operation, the LCD displays “Place Hand” together with the measured distance.

Place Hand Dist: XX.X cm
05
DECISION

Arduino Checks the Detection Threshold

The measured distance is checked against the programmed detection condition.

CONDITION Distance > 0 cm AND Distance ≤ 15 cm
YES Start Dispensing
NO Continue Monitoring
06
ACTUATION

Servo Motors Open the Tap

When a valid detection occurs, Arduino commands both servo motors to move from their closed position to the programmed open position.

CLOSED 0°
→
OPEN 90°
07
DISPENSING

Water Is Dispensed

The tap remains in its actuated position for approximately three seconds according to the current Phase 1 program.

Dispensing Water...
Programmed Duration 3 seconds
08
CLOSING

Servo Motors Close the Tap

After the programmed dispensing interval, Arduino commands both servos to return to the 0° closed position.

OPEN 90°
→
CLOSED 0°
09
COMPLETION

Completion Message Is Displayed

The LCD informs the user that the dispensing cycle has completed.

Thank You Visit Again
10
RESET

System Returns to Monitoring

After the completion message, the display is cleared and the main program loop continues measuring distance. The dispenser is ready for the next detection cycle.

Detect → Decide → Dispense → Close → Repeat
CONTROL LOGIC

Phase 1 Decision Logic

At its core, the control system follows one simple decision.

SENSOR INPUT Measure Distance
↓
DECISION Is distance between 0 and 15 cm?
NO Keep Monitoring

Continue measuring distance.

YES Start Dispensing

Open servos → wait 3 sec → close.

COMPONENT ROLES

How Each Major Component Contributes

INPUT

HC-SR04

Provides distance information to determine whether a hand is inside the detection zone.

PROCESSING

Arduino Uno

Executes the program, evaluates distance and coordinates the LCD and servo motors.

OUTPUT

Servo Motors

Convert Arduino commands into mechanical movement of the tap mechanism.

INTERFACE

16×2 LCD

Communicates instructions, distance and system status to the user.

IMPORTANT ENGINEERING NOTE

Software Command vs. Physical Tap Position

In the current Phase 1 design, Arduino commands the servos to 0° or 90°, but the software does not independently verify that the physical tap actually reached the requested position.

Mechanical alignment, servo linkage and calibration must therefore be checked during prototype assembly and testing.
