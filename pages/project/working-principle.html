WORKING PRINCIPLE

From Hand Detection to Automatic Dispensing.

AquaSense operates through a continuous sensing-and-actuation cycle. The ultrasonic sensor measures distance, the Arduino Uno evaluates the reading, and two servo motors automatically control the water dispensing mechanism when the programmed condition is satisfied.

CORE PRINCIPLE

A Closed Automated Operating Cycle

The prototype repeatedly monitors its surroundings and only activates the water dispensing mechanism when a valid object is detected within the programmed range.

01

Sense

The HC-SR04 ultrasonic sensor sends an ultrasonic pulse and measures how long the reflected echo takes to return.

02

Process

The Arduino Uno converts the echo duration into a distance value and checks whether the measured object is inside the programmed detection range.

03

Actuate

When the detection condition is valid, both servo motors move to their open position and mechanically operate the tap.

04

Dispense

Water is dispensed for approximately three seconds while the LCD displays the active dispensing status.

05

Close

Both servos automatically return to their 0° closed position after the programmed dispensing interval.

06

Repeat

After displaying the completion message, the system returns to distance monitoring and waits for the next valid detection.

OPERATION SEQUENCE

What Happens From Power-On to Reset

The following sequence directly represents the behavior programmed into the Phase 1 Arduino control system.

01
INITIALIZATION

System Powers On

When power is applied, the Arduino Uno initializes serial communication, the LCD, ultrasonic sensor pins and both servo motors.

Both servos are immediately commanded to the programmed closed position of 0°.

02
USER FEEDBACK

Startup Message Appears

The 16×2 LCD displays the startup message:

Automatic Water / Dispenser

The message remains visible for approximately two seconds before the normal monitoring cycle begins.

03
SENSING

Ultrasonic Distance Is Measured

Arduino sends a short trigger pulse to the HC-SR04 ultrasonic sensor. The sensor emits an ultrasonic pulse and measures the time required for its echo to return after reflecting from an object.

04
DISTANCE CALCULATION

Echo Time Is Converted Into Distance

The Arduino calculates the distance using the measured echo duration and the approximate speed of sound.

Distance = Duration × 0.034 ÷ 2

Division by two is required because the ultrasonic pulse travels from the sensor to the object and then returns to the sensor.

05
READY STATE

System Waits for a Hand

During normal monitoring, the LCD displays:

Place Hand

The second LCD row displays the continuously measured distance in centimeters.

06
DECISION

Arduino Checks the Detection Threshold

Every measured distance is evaluated against the programmed condition:

Distance > 0 cm AND Distance ≤ 15 cm

If the condition is false, the system continues monitoring. If the condition is true, the dispensing sequence begins.

07
ACTUATION

Servo Motors Open the Tap

Once valid detection occurs, Arduino commands both SG90 servo motors to move from the closed position:

0° → 90°

This servo movement mechanically operates the water tap.

08
DISPENSING

Water Flows for Three Seconds

While the tap is open, the LCD displays:

Dispensing / Water...

The program maintains the open servo position for approximately three seconds.

09
AUTOMATIC CLOSING

Servo Motors Close the Tap

After the three-second dispensing interval, both servos automatically return from:

90° → 0°

The mechanical tap returns to its closed position and water flow stops.

10
COMPLETION

User Receives Completion Feedback

After closing the tap, the LCD displays:

Thank You / Visit Again

The message remains visible for approximately two seconds.

11
RESET

Monitoring Automatically Restarts

The LCD is cleared and the program returns to its main loop. Distance measurement begins again and the system waits for the next valid hand detection.

ULTRASONIC SENSING

How the System Detects a Hand

AquaSense does not require physical contact because detection is performed using reflected ultrasonic sound.

TX

Trigger

Arduino sends a 10-microsecond HIGH pulse to the ultrasonic sensor's trigger pin.

WAV

Ultrasonic Pulse

The HC-SR04 emits a high-frequency sound pulse toward the area in front of the dispenser.

RX

Echo Return

When the sound reaches a hand or another object, part of the ultrasonic energy is reflected back toward the sensor.

CM

Distance

Arduino measures the echo travel time and converts it into a distance value in centimeters.

CONTROL DECISION

When Does the Tap Actually Open?

Servo actuation occurs only when the measured distance satisfies the programmed detection condition.

NO

Distance Above 15 cm

No dispensing action occurs. The servo motors remain at 0° and the system continues measuring distance.

YES

Distance Between 0 and 15 cm

A valid detection is recognized. Both servos move to 90° and the automatic dispensing sequence begins.

END

After Three Seconds

Both servos return to 0°, stopping the water flow and completing the dispensing cycle.

COMPONENT ROLES

What Each Main Component Does

Each hardware component performs a specific role within the sensing and control loop.

MCU

Arduino Uno

Acts as the central controller. It reads the ultrasonic sensor, calculates distance, makes control decisions, updates the LCD and controls both servo motors.

US

HC-SR04

Provides non-contact distance measurement used to determine whether a hand is inside the programmed detection zone.

S1

SG90 Servos

Convert Arduino control commands into physical movement that opens and closes the tap mechanism.

LCD

16×2 I2C LCD

Provides visual feedback including startup information, distance readings, dispensing status and completion messages.

LOGIC SUMMARY

One Complete AquaSense Cycle

Power On → Initialize Hardware → Display Startup Message → Measure Distance → Check Detection Threshold → Detect Hand → Open Servos → Dispense Water → Wait 3 Seconds → Close Servos → Display Completion Message → Return to Monitoring.
