AT A GLANCE

Phase 1 Project Snapshot

The first phase establishes the core sensing, control and mechanical automation required for a functional touchless dispensing prototype.

01

Problem

Conventional water dispensers generally require users to physically operate a tap, lever or button. Repeated physical contact can reduce convenience and may create hygiene concerns in frequently used environments.

02

Proposed Solution

AquaSense introduces automatic hand detection and servo-controlled tap operation. When a hand is detected within the programmed range, the system automatically starts and completes a controlled water dispensing cycle.

03

Main Objective

The objective of Phase 1 is to develop a functional prototype that demonstrates touchless detection, automatic actuation, user feedback and controlled dispensing using accessible embedded hardware.

PROBLEM DEFINITION

Why Automate a Conventional Water Dispenser?

Traditional water dispensing systems depend heavily on manual interaction. A user normally presses a button, moves a lever or turns a tap before water begins to flow.

In shared environments, the same physical control may be touched repeatedly by many users. Manual operation can also allow water to continue flowing if the tap is not properly returned to its closed position.

AquaSense investigates a simple engineering approach to reduce this dependency on physical interaction by combining proximity sensing, embedded decision-making and mechanical automation.

PROJECT OBJECTIVES

What Phase 1 Is Designed to Achieve

The prototype focuses on proving the essential engineering functions required for reliable touchless dispensing.

01

Detect the User

Continuously measure distance using the HC-SR04 ultrasonic sensor and identify when a hand enters the programmed detection range.

02

Automate Tap Control

Convert the sensor decision into mechanical movement using two SG90 servo motors that operate the dispensing mechanism.

03

Control Water Duration

Keep the tap open for a programmed period and automatically return the mechanism to its closed position.

04

Provide User Feedback

Use the 16×2 I2C LCD to display system status, measured distance, dispensing information and completion messages.

05

Integrate the Hardware

Combine sensing, processing, display, actuation and power components into one coordinated embedded system.

06

Develop the Enclosure

Create custom 3D-designed parts for housing and supporting the electronics and servo mechanism of the prototype.

CORE OPERATION

How AquaSense Responds to a User

The system continuously repeats a simple sensing, decision and actuation cycle.

01

Monitor

The ultrasonic sensor continuously measures the distance in front of the dispenser.

02

Detect

A valid detection occurs when the measured object is greater than 0 cm and within the programmed 15 cm threshold.

03

Actuate

Arduino commands both servo motors to move from 0° to the programmed 90° open position.

04

Dispense

Water is dispensed for approximately three seconds while the LCD informs the user that dispensing is active.

05

Reset

The servos return to 0°, the tap closes, a completion message is displayed and the system returns to monitoring mode.

TECHNOLOGY FOUNDATION

Five Engineering Layers Working Together

AquaSense is not only a sensor project. Phase 1 combines multiple engineering domains into one integrated prototype.

SEN

Sensing

HC-SR04 ultrasonic sensing provides non-contact distance measurement for detecting a user's hand.

MCU

Embedded Control

Arduino Uno executes the control logic, evaluates sensor readings and coordinates the complete dispensing sequence.

ACT

Mechanical Actuation

Dual SG90 servo motors convert electrical commands into physical movement required to operate the tap mechanism.

UI

User Feedback

A 16×2 I2C LCD communicates system status, measured distance and dispensing messages to the user.

CAD

Mechanical Design

Custom CAD models provide dedicated housings for the main electronics and servo actuation mechanism.
