PROJECT OVERVIEW

Engineering a Smarter Way to Dispense Water

AquaSense is a Phase 1 engineering prototype that combines ultrasonic sensing, embedded control, servo-based mechanical actuation and a custom 3D-designed enclosure to create a touchless water dispensing system.

AT A GLANCE

Phase 1 Project Snapshot

The first phase establishes the core sensing, control and mechanical automation required for touchless water dispensing.

Controller Arduino Uno
Detection Ultrasonic
Threshold ≤ 15 cm
Actuation Dual Servo
01 / PROBLEM

Why Touchless Dispensing?

Conventional manually operated water taps require users to physically touch the tap or control mechanism.

In frequently shared environments, repeated physical interaction with the same control surface is less convenient and creates an opportunity for unnecessary contact.

Engineering Challenge

How can a simple water tap be operated automatically when a user approaches, without requiring direct physical contact?

02 / SOLUTION

Automated Sensor-Based Control

The proposed system uses an HC-SR04 ultrasonic sensor to continuously measure the distance in front of the dispenser.

When a hand or suitable object is detected within the programmed 15 cm threshold, the Arduino Uno activates two servo motors connected to the tap mechanism.

The tap remains actuated for approximately three seconds before the servos automatically return to the closed position.

PROJECT OBJECTIVES

What Phase 1 Is Designed to Achieve

01

Touchless Detection

Detect a user's hand automatically using non-contact ultrasonic distance sensing.

02

Automatic Actuation

Operate the tap mechanism automatically using servo motors controlled by Arduino.

03

User Feedback

Display system instructions, measured distance and dispensing status through a 16×2 I2C LCD.

04

Controlled Dispensing

Use a programmed dispensing sequence with automatic opening and closing.

05

Mechanical Integration

Integrate electronics and servo mechanisms into custom-designed 3D-printable enclosures.

06

Modular Foundation

Create a Phase 1 platform that can later support smarter monitoring and sensing features.

CORE FEATURES

Phase 1 System Capabilities

01

Non-Contact Hand Detection

The ultrasonic sensor measures distance continuously and triggers the system when the programmed threshold condition is satisfied.

02

Arduino-Based Decision Control

Arduino Uno processes sensor data and coordinates LCD feedback and servo operation.

03

Dual Servo Tap Mechanism

Two servo motors operate together according to the programmed 0° closed and 90° open positions.

04

Real-Time LCD Status

The LCD communicates startup, hand-placement guidance, measured distance, dispensing status and completion messages.

05

Custom 3D Design

Dedicated main and servo enclosures provide a mechanical structure for integrating the project components.
