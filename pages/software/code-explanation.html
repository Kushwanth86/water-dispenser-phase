PROGRAM BREAKDOWN

How the Arduino Program Is Organized

The program can be understood as a sequence of software layers. Each layer performs a specific task required by the automatic dispenser.

01 — LIBRARIES

Required Software Libraries

The program begins by loading libraries that provide ready-made functions for I2C communication, LCD control and servo motor control. 

#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <Servo.h>
I2C

Wire.h

Handles I2C communication used by the Arduino Uno to communicate with the LCD interface.

LCD

LiquidCrystal_I2C.h

Provides functions for initializing, clearing and displaying text on the 16×2 I2C LCD.

SER

Servo.h

Allows the Arduino to generate the control signals required to position the SG90 servo motors.

02 — SYSTEM OBJECTS

LCD and Servo Objects

Software objects are created so the program can communicate with the LCD and control both servo motors. 

LiquidCrystal_I2C lcd(0x27, 16, 2);

Servo servo1;
Servo servo2;
LCD

LCD Object

The LCD is configured as a 16-column, 2-row display using the I2C address 0x27.

S1

Servo 1

Represents the first servo motor used in the mechanical tap-control mechanism.

S2

Servo 2

Represents the second servo motor, allowing coordinated mechanical actuation.

03 — PIN DEFINITIONS

Connecting Software to Hardware

Pin constants tell the Arduino program which physical pins are connected to the ultrasonic sensor and servo motors. 

const int trigPin = 9;
const int echoPin = 10;

const int servo1Pin = 6;
const int servo2Pin = 7;
D9

Trigger

Sends the ultrasonic trigger pulse.

D10

Echo

Receives the returning ultrasonic pulse.

D6

Servo 1

Controls the first servo motor.

D7

Servo 2

Controls the second servo motor.

04 — SYSTEM SETTINGS

Detection and Servo Parameters

These constants define the important operating limits of the automatic dispensing system. 

const int detectDistance = 15;   // cm

const int openAngle = 90;
const int closeAngle = 0;
15

Detection Distance

A hand detected within approximately 15 cm can trigger the dispensing sequence.

90°

Open Position

The programmed servo position used when operating the tap mechanism.

0°

Closed Position

The servo position used to return the mechanism to its normal closed state.

05 — SETUP()

System Initialization

The setup() function runs only once when the Arduino is powered on or reset. Its job is to prepare every hardware subsystem before normal operation begins.

01
SERIAL

Start Serial Communication

Serial communication at 9600 baud allows sensor readings and debugging information to be viewed through the Serial Monitor.

02
LCD

Initialize the Display

The LCD is initialized and its backlight is activated so the system can provide visual feedback.

03
SENSOR

Configure Ultrasonic Pins

The trigger pin is configured as an output and the echo pin as an input.

04
SERVOS

Attach Servo Motors

Both servo objects are connected to their assigned Arduino control pins.

05
SAFE STATE

Move to Closed Position

The servo motors begin at the programmed closed angle so the tap starts in a controlled state.

06 — ULTRASONIC MEASUREMENT

How Distance Is Calculated

The HC-SR04 determines distance by measuring how long an ultrasonic pulse takes to travel to an object and return to the sensor.

01

Clear Trigger

The trigger pin is first held LOW briefly to ensure a clean pulse.

02

Send Trigger Pulse

Arduino sends a short HIGH pulse to the HC-SR04 trigger pin.

03

Measure Echo Time

The echo pulse duration represents the ultrasonic wave's round-trip travel time.

04

Calculate Distance

The measured travel time is converted into distance using the approximate speed of sound.

DISTANCE FORMULA Distance = (Echo Time × Speed of Sound) ÷ 2

Division by two is required because the ultrasonic pulse travels from the sensor to the object and then returns to the sensor.

07 — LOOP()

Continuous Monitoring

After initialization, the Arduino enters loop(). Unlike setup(), this function repeats continuously for as long as the system has power.

01

Read Distance

Obtain the latest distance measurement from the HC-SR04 sensor.

02

Update Feedback

Display system information and distance status on the LCD.

03

Evaluate Distance

Compare the measured value with the programmed 15 cm detection threshold.

04

Make Decision

Either activate the dispensing mechanism or continue monitoring.

08 — DECISION LOGIC

Is a Hand Inside the Detection Zone? 

if (distance > 0 && distance <= detectDistance)
{
    // Start dispensing sequence
}

Two conditions must be satisfied before the dispenser activates.

> 0

Valid Measurement

The measured distance must be greater than zero to avoid treating an invalid reading as a detection.

≤15

Inside Detection Zone

The object must be within the programmed 15 cm activation distance.

YES

Detection Confirmed

Arduino begins the dispensing sequence.

NO

Continue Monitoring

The servo motors remain in the closed position and another distance reading is taken.

09 — ACTUATION

Servo-Controlled Tap Operation

When a valid hand detection occurs, Arduino commands the servo motors to operate the mechanical tap mechanism.

01
DETECTION

Hand Confirmed

The ultrasonic reading satisfies the programmed activation condition.

02
OPEN

Servos Move to 90°

Both servo motors move toward the programmed open position.

03
DISPENSE

Water Flows

The tap remains mechanically actuated for the programmed dispensing period.

04
CLOSE

Servos Return to 0°

Both servo motors return to their closed position and water flow stops.

05
RESET

Monitoring Resumes

The system returns to ultrasonic monitoring and waits for the next valid detection.

10 — USER FEEDBACK

LCD Communication

The LCD provides a simple interface between the embedded system and the user.

ON

Startup

Displays the initial system message when AquaSense is powered on.

CM

Monitoring

Provides distance or hand-placement information during normal operation.

RUN

Dispensing

Indicates when a hand has been detected and the dispensing sequence is active.

END

Completion

Provides feedback when the dispensing cycle finishes and the tap returns to the closed state.

COMPLETE CONTROL CYCLE

From Power-On to Water Dispensing

The entire embedded program can be summarized as one repeating control sequence.

01

System Powers On

Arduino initializes all connected subsystems.

02

Ultrasonic Sensor Measures Distance

HC-SR04 continuously checks the detection area.

03

Arduino Evaluates the Reading

The measured distance is compared with the 15 cm threshold.

04

Hand Is Detected

A valid reading inside the detection zone activates the next stage.

05

Servo Motors Open the Tap

Both servos move to their programmed actuation position.

06

Water Is Dispensed

The mechanical system maintains the open state for the programmed period.

07

Tap Closes

The servo motors return to the closed position.

08

System Returns to Monitoring

The loop repeats and AquaSense waits for the next detection.

HARDWARE + SOFTWARE

Every Software Command Has a Physical Effect

The Arduino program does not operate independently from the hardware. Every pin assignment and control command corresponds to a physical component in the AquaSense circuit.

IN

Sensor Input

HC-SR04 provides distance information to the Arduino.

CPU

Processing

Arduino evaluates the sensor reading using the programmed logic.

OUT

Servo Output

Arduino sends position commands to both servo motors.

UI

LCD Output

The display communicates system status to the user.
