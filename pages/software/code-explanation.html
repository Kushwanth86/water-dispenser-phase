04 — SOFTWARE

Code Explanation

Breakdown of the embedded architecture and logic sequences.

The setup() function prepares the microcontroller environment. It defines the trigger pin as an output and the echo pin as an input. It securely attaches the servo to pin 6 and immediately writes it to 0 (closed state) to ensure the valve doesn't accidentally open upon boot. Finally, it initializes the 16x2 LCD display and prints a welcome message.

In the main loop(), the Arduino pulls the trigger pin LOW for 2µs, then HIGH for 10µs. This specific timing fires a 40kHz acoustic burst from the HC-SR04. The pulseIn() function calculates how long it takes for the echo to return. This duration is mathematically converted into centimeters using the formula (duration / 2) / 29.1.

The software checks if the calculated distance is less than THRESHOLD_CM (15cm) and greater than zero (to ignore false negative errors). If a hand or glass is detected, the servo writes to 90 degrees, pulling the physical valve open. It then triggers a 1-second delay buffer to provide a smooth pour and prevent mechanical jitter.

Throughout the logic branching, the LCD is updated in real-time. It displays "Dispensing..." when the threshold is met, and "Ready to Serve" when idle. An overall loop delay of 200ms is added at the end of the script to prevent CPU overloading and stabilize sensor readings across consecutive loops.
