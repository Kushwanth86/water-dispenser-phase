EMBEDDED SOFTWARE

The Logic Behind AquaSense.

AquaSense is controlled by an Arduino Uno program that continuously measures distance, detects a user's hand, controls two servo motors, updates the LCD and manages the complete automatic dispensing cycle.

SOFTWARE RESPONSIBILITY

What the Arduino Program Controls

The embedded program connects sensing, decision-making, user feedback and mechanical actuation into one continuous automatic control loop.

01

Distance Measurement

Generates the ultrasonic trigger pulse, measures echo duration and calculates the distance between the sensor and the user's hand.

02

Detection Logic

Compares the measured distance with the programmed detection threshold before starting the dispensing cycle.

03

Servo Control

Commands both SG90 servo motors to move between their programmed closed and open positions.

04

LCD Feedback

Displays startup information, hand detection status and system feedback to the user.

SOFTWARE ↔ HARDWARE

Program Pin Configuration

The pin definitions in the Arduino program must match the physical circuit connections.

D6

Servo Motor 1

Digital control output for the first SG90 servo motor.

D7

Servo Motor 2

Digital control output for the second SG90 servo motor.

D9

HC-SR04 Trigger

Sends the trigger pulse used to begin an ultrasonic distance measurement.

D10

HC-SR04 Echo

Receives the returning ultrasonic echo pulse for distance calculation.

A4

LCD SDA

I2C serial data connection between the Arduino Uno and LCD module.

A5

LCD SCL

I2C clock connection used for LCD communication.

PROGRAM ARCHITECTURE

How the Software Is Structured

The program follows the standard Arduino architecture with initialization performed once and control logic repeated continuously.

01
LIBRARIES

Load Required Libraries

Servo and LCD libraries provide the functions required to control the actuators and user display.

02
CONFIGURATION

Define Pins and Objects

Sensor pins, servo objects, LCD configuration and system variables are defined before execution begins.

03
SETUP()

Initialize the System

The Arduino configures the sensor pins, attaches the servos, initializes the LCD and moves the system into its starting state.

04
LOOP()

Monitor Continuously

The controller repeatedly measures distance and evaluates whether a hand is inside the programmed detection range.

05
ACTUATION

Execute Dispensing Cycle

When the detection condition is valid, the servo motors operate the tap for the programmed dispensing duration and then return to the closed state.

CORE CONTROL LOGIC

Detection Decision

Water dispensing begins only when the ultrasonic measurement satisfies the programmed detection condition.

CONDITION

Distance > 0 cm AND Distance ≤ 15 cm

A distance greater than zero confirms that a valid ultrasonic measurement was received. A distance of 15 cm or less indicates that an object or hand is inside the programmed activation zone.

YES

Valid Detection

The Arduino starts the automatic dispensing sequence and commands the servo mechanism.

NO

No Valid Detection

The tap remains closed and the controller continues monitoring the ultrasonic sensor.

ARDUINO SOURCE

Phase 1 Program

The complete Arduino sketch is stored as a downloadable .ino file in the project repository.

automatic-water-dispenser.ino 
// AquaSense
// Automatic Touchless Water Dispenser
// Phase 1 Embedded Control Program

#include <Servo.h>
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

// ------------------------------------
// PIN CONFIGURATION
// ------------------------------------

const int trigPin = 9;
const int echoPin = 10;

const int servoPin1 = 6;
const int servoPin2 = 7;

// ------------------------------------
// SYSTEM OBJECTS
// ------------------------------------

Servo servo1;
Servo servo2;

LiquidCrystal_I2C lcd(0x27, 16, 2);

// ------------------------------------
// SYSTEM VARIABLES
// ------------------------------------

long duration;
float distance;

const int detectionDistance = 15;

const int closedAngle = 0;
const int openAngle = 90;

const unsigned long dispensingTime = 3000;


// ------------------------------------
// SETUP
// ------------------------------------

void setup()
{
    Serial.begin(9600);

    pinMode(trigPin, OUTPUT);
    pinMode(echoPin, INPUT);

    servo1.attach(servoPin1);
    servo2.attach(servoPin2);

    servo1.write(closedAngle);
    servo2.write(closedAngle);

    lcd.init();
    lcd.backlight();

    lcd.setCursor(0, 0);
    lcd.print("Automatic Water");

    lcd.setCursor(0, 1);
    lcd.print("Dispenser");

    delay(2000);

    lcd.clear();
}


// ------------------------------------
// MAIN LOOP
// ------------------------------------

void loop()
{
    distance = measureDistance();

    Serial.print("Distance: ");
    Serial.print(distance);
    Serial.println(" cm");

    lcd.setCursor(0, 0);
    lcd.print("Place Hand      ");

    lcd.setCursor(0, 1);
    lcd.print("Dist: ");
    lcd.print(distance);
    lcd.print(" cm   ");

    if (distance > 0 && distance <= detectionDistance)
    {
        dispenseWater();
    }

    delay(200);
}


// ------------------------------------
// DISTANCE MEASUREMENT
// ------------------------------------

float measureDistance()
{
    digitalWrite(trigPin, LOW);

    delayMicroseconds(2);

    digitalWrite(trigPin, HIGH);

    delayMicroseconds(10);

    digitalWrite(trigPin, LOW);

    duration = pulseIn(echoPin, HIGH, 30000);

    if (duration == 0)
    {
        return -1;
    }

    float measuredDistance;

    measuredDistance =
        duration * 0.0343 / 2;

    return measuredDistance;
}


// ------------------------------------
// WATER DISPENSING FUNCTION
// ------------------------------------

void dispenseWater()
{
    lcd.clear();

    lcd.setCursor(0, 0);
    lcd.print("Hand Detected");

    lcd.setCursor(0, 1);
    lcd.print("Dispensing...");

    servo1.write(openAngle);
    servo2.write(openAngle);

    delay(dispensingTime);

    servo1.write(closedAngle);
    servo2.write(closedAngle);

    lcd.clear();

    lcd.setCursor(0, 0);
    lcd.print("Water Stopped");

    delay(1000);

    lcd.clear();
}
