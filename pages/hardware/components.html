03 — HARDWARE

System Components

Detailed breakdown of the electronic peripherals utilized in the prototype.

Arduino Uno

Role: Main Logic Controller

MCU: ATmega328P

Voltage: 5V Operating

Processes sensor interrupts and commands the servo mechanism.

HC-SR04

Role: Object Detection

Range: 2cm – 400cm

Frequency: 40kHz

Emits acoustic pulses to detect hands or containers below the nozzle.

SG90 Servo

Role: Mechanical Actuation

Torque: 1.8 kgf·cm

Rotation: 180°

Translates PWM signals into rotational force to physically open the valve.

16x2 LCD

Role: User Interface

Interface: Parallel / I2C

Displays real-time system status, dispense notifications, and error codes.

Power Module

Role: System Power

Output: 9V / 5V DC

Supplies consistent voltage to the Arduino board and isolates the servo power draw.
