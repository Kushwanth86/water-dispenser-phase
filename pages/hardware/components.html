Primary Components

Core electromechanical hardware elements utilized in the Phase 1 prototype.

Arduino Uno Rev3

Role: Central processing unit. Handles sensor inputs and logic.

HC-SR04 Ultrasonic

Role: Object detection. Emits acoustic pulses for distance calculation.

SG90 Micro Servo

Role: Mechanical actuator. Physically controls the water valve.

16×2 LCD Display

Role: User interface. Displays real-time status feedback.

Power Supply

Role: Energy source. Provides stable DC power to components.
