CORE COMPONENTS

Hardware Used in Phase 1

Each component has a specific responsibility in the sensing, processing, actuation or feedback chain.

MCU

Arduino Uno

The central embedded controller of the AquaSense system.

It reads ultrasonic sensor data, calculates distance, evaluates the detection threshold, controls both servo motors and updates the LCD.

US

HC-SR04

An ultrasonic distance sensor used for touchless hand detection.

It allows the system to detect a nearby object without requiring any physical button or switch.

S1

SG90 Servo Motor 1

Receives position commands from Arduino through digital pin D6.

It contributes to the mechanical movement required to operate the water tap.

S2

SG90 Servo Motor 2

Receives position commands from Arduino through digital pin D7.

It operates together with Servo 1 during the automatic opening and closing cycle.

LCD

16×2 I2C LCD

Provides visual feedback about the current system state.

It displays startup messages, measured distance, dispensing status and completion information.

PWR

Power & Wiring System

Provides electrical power and signal connections between the Arduino, sensor, servos and LCD.

Reliable power delivery is particularly important for the servo motors because they require more current than logic-level sensors.

MAIN CONTROLLER

Arduino Uno

The Arduino Uno acts as the brain of the Phase 1 AquaSense prototype.

CPU

Central Processing

Executes the complete Arduino program and coordinates every major subsystem.

IN

Sensor Input

Generates the ultrasonic trigger pulse and measures the returning echo duration from the HC-SR04.

LOG

Decision Logic

Calculates distance and checks whether the measured object is within the programmed 15 cm detection threshold.

OUT

Output Control

Controls both servo motors and sends information to the LCD based on the current operating state.

TOUCHLESS DETECTION

HC-SR04 Ultrasonic Sensor

The ultrasonic sensor is the primary input device that enables touchless operation.

01

Arduino Sends Trigger

Arduino sends a short pulse through digital pin D9 to the sensor's TRIG input.

02

Sensor Emits Ultrasonic Wave

The HC-SR04 transmits an ultrasonic sound pulse toward the area in front of the dispenser.

03

Echo Returns

When the wave reaches a hand or another object, part of the signal reflects back toward the sensor.

04

Arduino Measures Echo

The echo pulse is received through digital pin D10 and its duration is used to calculate distance.

MECHANICAL ACTUATION

Dual SG90 Servo System

Two servo motors convert Arduino commands into physical motion that operates the water tap mechanism.

S1

Servo Motor 1

Signal Pin: Arduino D6

Operates as part of the dual-servo mechanical dispensing mechanism.

S2

Servo Motor 2

Signal Pin: Arduino D7

Moves together with Servo 1 during opening and closing.

0°

Closed Position

Both servo motors are programmed to 0° when the dispensing mechanism is closed.

90°

Open Position

During valid hand detection, both servos move to the programmed 90° position.

SERVO CONTROL

Mechanical Actuation Sequence

01

Standby

Servo 1 = 0°
Servo 2 = 0°

The tap remains in its closed state.

02

Valid Hand Detection

Arduino detects an object within the programmed 15 cm range.

03

Open

Servo 1 → 90°
Servo 2 → 90°

The mechanical tap is operated.

04

Dispense

The servos remain in the open position for approximately three seconds.

05

Close

Servo 1 → 0°
Servo 2 → 0°

The tap automatically returns to its closed position.

USER INTERFACE

16×2 I2C LCD Display

The display provides simple visual communication between the embedded system and the user.

16×2

Display Format

Two rows with sixteen character positions per row.

I2C

Communication

Uses the I2C protocol to reduce the number of controller pins required for display communication.

SDA

Data Line

On the Arduino Uno, the I2C SDA connection corresponds to A4 / SDA.

SCL

Clock Line

On the Arduino Uno, the I2C SCL connection corresponds to A5 / SCL.

27

Configured Address

The current program initializes the LCD using I2C address: 0x27.

POWER SYSTEM

Reliable Power for Electronics and Actuation

The power arrangement is an important part of the physical AquaSense prototype, especially because servo motors can require considerably more current than sensors and logic devices.

MCU

Controller Power

The Arduino Uno provides the embedded processing platform and interfaces with the sensor, display and servo control signals.

5V

Logic-Level Devices

The HC-SR04 and common 16×2 I2C LCD modules operate within the 5 V logic environment used by the Arduino Uno.

AMP

Servo Current

Servo motors can produce short current peaks during movement or mechanical load. The power source must be capable of supporting both servos reliably.

GND

Common Ground

If the servos use an external regulated power source, its ground should be connected to the Arduino ground to provide a common reference for the servo control signals.

HARDWARE RELATIONSHIP

How the Components Work as One System

HC-SR04 detects the user's hand → Arduino Uno calculates the distance → Arduino checks the 15 cm threshold → SG90 servo motors operate the tap → Water is dispensed → Servos return to the closed position.

Throughout this sequence, the 16×2 I2C LCD provides visual feedback about the current state of the system.
