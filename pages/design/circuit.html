ELECTRICAL ARCHITECTURE

How the Circuit Is Organized

The Arduino Uno sits at the center of the electrical architecture and communicates with each subsystem through dedicated signal connections.

IN

Sensor Interface

The HC-SR04 communicates with Arduino through separate trigger and echo lines.

TRIG → D9
ECHO → D10

MCU

Controller

Arduino Uno processes sensor data, calculates distance and controls the system according to the embedded program.

OUT

Actuator Interface

Two digital control signals connect the Arduino to the servo motors.

Servo 1 → D6
Servo 2 → D7

I2C

Display Interface

The 16×2 LCD communicates through the Arduino Uno I2C bus.

SDA → A4
SCL → A5

SIGNAL FLOW

Electrical Information Path

The circuit carries both sensor information and controller commands during every operating cycle.

01

Arduino → HC-SR04

Arduino sends a trigger pulse through digital pin D9.

02

HC-SR04 → Arduino

The sensor returns an echo pulse through digital pin D10.

03

Arduino Processes Distance

The echo duration is converted into a distance measurement and compared with the 15 cm trigger threshold.

04

Arduino → Servo Motors

When detection is valid, control signals are sent through D6 and D7 to move both servos to 90°.

05

Arduino → LCD

The controller updates the display through I2C to show the current operating state.

06

Arduino → Servo Close

After approximately three seconds, Arduino commands both servos back to 0°, closing the tap mechanism.

ELECTRICAL DESIGN

Power Connections vs Signal Connections

These two types of wiring perform different functions and should not be confused during assembly or troubleshooting.

SIG

Signal Connections

Signal wires carry information or control commands.

Examples:

HC-SR04 TRIG
HC-SR04 ECHO
Servo control lines
LCD SDA and SCL

PWR

Power Connections

Power wires supply electrical energy to operate the controller, sensor, display and servo motors.

Servo motors require particular attention because their current demand can be much higher than logic devices.

GND

Ground Reference

Components communicating through electrical signals need a common reference.

If the servos use an external regulated power supply, the external supply ground should be connected to Arduino ground.

IMPORTANT ENGINEERING NOTE

Servo Power Must Be Designed Carefully

Two SG90 servo motors can create short current peaks when starting, moving or operating under mechanical load.

If the power source cannot provide sufficient current, symptoms can include servo jitter, weak movement, Arduino resets, unstable LCD behavior or unreliable ultrasonic readings.

For the final physical implementation, the servo power arrangement should be selected according to the actual prototype load and tested under real operating conditions.

We are intentionally not publishing an unverified battery voltage or current rating here. The final specification should match the real power system used in the completed prototype.

HARDWARE + SOFTWARE

The Circuit Matches the Embedded Program

The physical wiring and Arduino program must use the same pin assignments.

Servo 1 = D6 • Servo 2 = D7 • HC-SR04 Trigger = D9 • HC-SR04 Echo = D10 • LCD SDA = A4 • LCD SCL = A5.

If a physical wire is moved to another Arduino pin, the corresponding pin definition in the source code must also be updated.
